# Nusa Music

Modern offline Android music player.

## Stack
- Kotlin
- Jetpack Compose
- Material 3
- AndroidX Media3 / ExoPlayer
- MediaSession

## v1 foundation
- Scan local audio from the Android device
- Search songs by title, artist, and album
- Tap a song to start playback
- Background playback service
- Android media session integration
- Modern dark UI foundation

## Planned next features
- Album artwork
- Mini player
- Full Now Playing screen
- Queue
- Playlists
- Favorites
- Albums and artists
- Sleep timer
- Equalizer
- Settings
